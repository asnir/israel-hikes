# Data sources and limitations

The JSON preserves the legacy directory's source links and check dates. It is not a current reopening/closure verification. Five recommendations were checked on October 9, 2026; 169 extended records are planning leads; 59 segments are source descriptions rather than verified outings.

150 lead records derive from a shared reference document, with private URLs, personal narratives and irrelevant sensitive commentary removed. The original document is not distributed. Generic source marker: `מסמך משותף`. Trail facts remain distinct from live conditions.

Public route sources include:
- https://www.nakeb.co.il/hikes
- https://www.parks.org.il/trip/
- https://www.kkl.org.il/travel/trips/
- https://mhg.rgl.org.il/שביל-הגולן/
- Individual Nakeb, Shvilist, operator and guide links in each record.

Closure-check sources:
- https://www.parks.org.il/newsflash/maslulim-2/
- https://www.kkl.org.il/recreation-and-tours/messages/

OSM map and geocoding attribution: © OpenStreetMap contributors. Data is available under ODbL; see https://www.openstreetmap.org/copyright. OSRM road-distance matrices were computed from OSM-derived routing on October 9, 2026. Any database-use obligations remain separate from the MIT code licence.

City points are approximate locality/neighborhood geocoding results, not personal addresses. Ramat Gan and Jerusalem legacy estimates retain the old measurements with origin details withheld. There are 187 source-grounded starts and 46 records without a start coordinate. No location was invented to fill a gap.

Source photos from the former page were deliberately not copied into this open-source site because a verified redistribution licence was not available. The labelled decorative landscape drawings are original and depict no particular trail.

All linked source content remains subject to its source's terms. Contributors must supply reusable facts, not copied protected narratives or imagery.
